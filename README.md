# Chicago website

The public website for Chicago, the Swedish card game for iPhone. GitHub Pages serves it at https://mcederdev.github.io/chicago/.

Status: coming soon to the App Store (not released yet). When the app is live, replace the "Coming soon" status box in `index.html` with Apple's official App Store badge linked to the app, and add the `apple-itunes-app` meta tag (placeholder comment in the head).
